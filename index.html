This page reads your private hub on GitHub. It needs a read-only key (a "fine-grained token") once. The key stays in this browser on this computer.

One-time setup, about 2 minutes

  1. Open github.com/settings/personal-access-tokens/new (signed in as v7skull).
  2. Name it Wire. Set expiration to 90 days.
  3. Repository access: Only select repositories, then choose kevin-r2-claude-hub.
  4. Permissions, Repository: Contents: Read and write if you want to tick off your to-dos here (or Read-only to only view). Metadata is added automatically. Nothing else.
  5. Generate, copy the token, and paste it below.

On your phone: on your PC's Wire, click Pair a phone at the bottom, then tap Scan pairing code here and point the camera at it.
