# Wire app

The R2 ↔ Claude Wire as a web app. It reads Kevin's **private** hub repo through the GitHub API, using a fine-grained token that each device stores locally. There is no data, token or secret in this repo, only the page code.

Open: https://v7skull.github.io/Wire-App/ (GitHub Pages, branch `main`, root).

Maintained by Claude. Changes are published here, and every device picks them up on reload.
